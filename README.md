# NetGAF

Desktop-прототип для ВКР «Программное средство для поиска сетевых аномалий путем
анализа двумерных изображений». Интерфейс на русском языке, Python + PySide6,
свёрточный автоэнкодер PyTorch на CPU. Обработка локальная, без загрузки захватов в облачные API.

Программа читает **PCAP/PCAPNG**, строит временные ряды по IP-узлам, преобразует
три синхронных признака в **GASF или GADF** и отмечает окна с высокой ошибкой
восстановления изображения. Признаки: число пакетов, число захваченных байтов кадра,
число уникальных TCP/UDP-портов назначения. Для ICMP число портов равно нулю.

Это первая реализация по приложенной НИР. Пользователь выбрал Windows и Linux,
офлайн-анализ и показательные тесты с разными аномалиями. Требования руководителя
и реальные экспериментальные данные ещё уточняются; научные результаты не заявляются.

## Установка и запуск

Для Windows: [скачайте установщик NetGAF 0.2.0](https://github.com/Omniphob1a/maksim/releases/download/v0.2.0-windows-3a33710/NetGAF-Setup-0.2.0-x64.exe)
и запустите его. Другие версии доступны на [странице выпусков](https://github.com/Omniphob1a/maksim/releases).
Установщик включает Python, Qt, PyTorch CPU, готовую модель и примеры.
После установки нажмите **«Открыть готовый пример»**. Инструкция доступна через
меню «Пуск» и **F1** в программе. Публикация установщика выполняется только
после автоматических проверок Windows, установки и удаления.

Для запуска из исходников (Windows/Linux):

Нужны Python 3.11–3.13 и [uv](https://docs.astral.sh/uv/getting-started/installation/).
Windows 10/11 и Linux являются целевыми платформами; автоматические проверки
пройдены на Windows Server 2022 и Linux. Отдельный сетевой драйвер для чтения файлов не нужен.

```bash
cd maksim
uv sync --frozen --extra dev
uv run --frozen netgaf-desktop
```

Обычная установка содержит Qt и PyTorch CPU. На Linux необходимы системные
библиотеки Qt: OpenGL/EGL, fontconfig, xkbcommon, а для показа окна — графическая сессия.
На облачной машине без дисплея функциональные проверки Qt запускаются с
`QT_QPA_PLATFORM=offscreen`; видимое окно появляется при локальном запуске.

## Как пользоваться

1. Добавьте захваты **нормального** трафика в список обучения. Подтвердите состав данных.
2. Выберите интервал, размер и шаг окна, направление и GAF. Начальные параметры
   из НИР: 1 секунда, 32 отсчёта, три канала; шаг окна — 16 отсчётов.
3. Обучите модель. Первые 70% времени каждого сегмента используются для обучения,
   последние 30% — для калибровки порога. Разделение предшествует созданию окон.
4. Сохраните модель `.ngaf` для последующих запусков.
5. Выберите отдельный захват для анализа. Его обработка использует параметры модели.
6. Выберите окно в таблице: доступны исходные ряды, GAF-каналы и реконструкции.
7. Экспортируйте CSV или JSON. JSON включает параметры и сведения об обучении.

В установочной версии нажмите «Открыть готовый пример» для запуска демонстрации
с готовой моделью. Для самостоятельного обучения нажмите «Создать демоданные», выберите пустую папку, затем
обучите модель на автоматически выбранном `normal.pcap` и анализируйте `mixed.pcap`.
Генератор записывает синтетические пакеты только в файлы, без передачи по сети.
Метки сценариев находятся в `labels.json`. Создаются отдельные файлы
`packet_burst.pcap` (всплеск пакетов), `byte_surge.pcap` (рост байтов),
`port_diversity.pcap` (рост числа портов) и `mixed.pcap` с тремя последовательными
сценариями. Кнопка «Проверить демосценарии» показывает TP/FP/FN, Precision,
Recall, F1 и FPR для каждого файла при неизменном пороге модели.

## Командная строка

```bash
uv run --frozen netgaf demo artifacts/demo
uv run --frozen netgaf train artifacts/demo/normal.pcap --model artifacts/demo/model.ngaf --epochs 20
uv run --frozen netgaf analyze artifacts/demo/mixed.pcap --model artifacts/demo/model.ngaf --output artifacts/demo/report.json
uv run --frozen netgaf analyze artifacts/demo/mixed.pcap --model artifacts/demo/model.ngaf --output artifacts/demo/report.csv
uv run --frozen netgaf evaluate-demo artifacts/demo --model artifacts/demo/model.ngaf --output artifacts/demo/evaluation.json
uv run --frozen pytest
uv run --frozen ruff check .
```

Команда `demo` отказывается перезаписывать существующий демонстрационный набор.
Захваты, модели и отчёты в `artifacts/` исключены из Git. Секреты и сетевой доступ
для анализа не нужны. Первичная установка требует PyPI и `download.pytorch.org`.

## Что означает результат

Оценка — средняя квадратичная ошибка (MSE) по трём GAF-каналам. Порог — заданный
квантиль ошибок на нормальной валидационной части, по умолчанию 0.99. Решение:
`MSE > порог`. Порог не подбирается по анализируемому файлу. «Подозрительное окно»
указывает на отклонение модели, а не устанавливает тип или факт сетевой атаки.

Масштабирование фиксируется по обучающим данным каждого канала. Выходы за диапазон
ограничиваются до [0,1] перед GAF, но их количество и величина записываются отдельно.
Для константного обучающего признака используется масштаб `max(abs(value), 1)`;
изменение константы также фиксируется как выход за диапазон.

Матрицы для модели остаются float32, цветные изображения служат визуализацией.
Восстановление ряда из диагонали GASF математически однозначно на [0,1], но
ограничивается погрешностью float32, особенно около нуля. Для проверки формул
преобразование также поддерживает float64.
Модели сохраняются как JSON + числовые массивы NPZ без pickle и произвольного Python-кода.

## Границы первой версии

- Офлайн-анализ; захват с сетевой карты пока не реализован.
- IPv4/IPv6, TCP/UDP и IP-пакеты без портов. Не-IP кадры учитываются в статистике пропусков.
  Используется первый внешний IP-заголовок; туннели и фрагменты не собираются обратно.
- Размер означает **захваченные байты кадра**, а не исходную длину на линии.
  Укороченные захватом кадры учитываются отдельно; порт может быть недоступен.
- Время отображается в UTC. Окна имеют полуоткрытые границы `[начало, конец)`.
  Последний неполный интервал сегмента исключается. Пустые интервалы внутри захвата
  заполняются нулями; это предполагает непрерывность захвата, потери определить нельзя.
- Разрыв более 120 секунд создаёт отдельный сегмент. Окна не пересекают разрывы
  и границы файлов. Нарушение хронологического порядка меток вызывает понятную ошибку.
- Есть ограничения длительности, числа агрегатов/окон/элементов признаков;
  данные не усекутся молча. GAF вычисляется партиями.
- Синтетический набор проверяет механику, но не качество на реальной сети.
  Сравнение с MTF/исходными рядами и независимые
  эксперименты CIC-IDS2017/LYCOS-IDS2017 остаются задачами исследовательского этапа.
- Квантиль на малой валидации не гарантирует заданную частоту ложных тревог.
  Обучение на ненормальном трафике и сдвиг условий сети ухудшают результат.
