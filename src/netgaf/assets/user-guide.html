1. Установка и запуск

  1. Запустите NetGAF-Setup-0.2.0-x64.exe.
  2. Оставьте предложенную папку установки. При желании включите создание ярлыка на рабочем столе.
  3. Нажмите «Установить», затем «Завершить».
  4. Запускайте NetGAF через меню «Пуск» или ярлык.
Python и библиотеки входят в установщик. Команды вводить не нужно. Анализ выполняется на CPU; отдельная видеокарта и сетевой драйвер для чтения файлов не требуются. После установки Интернет для анализа не нужен.

Первый запуск может быть дольше обычного: загружаются библиотеки анализа. Инструкция доступна через меню «Пуск → NetGAF → Инструкция» и по клавише F1 в программе.

2. Проверка за один шаг

  1. В левой панели нажмите «Открыть готовый пример».
  2. Программа сама загрузит готовую демонстрационную модель и обработает файл mixed.pcap.
  3. На вкладке «Обзор трафика» посмотрите оценку аномальности: линия порога позволяет увидеть отмеченные окна.
  4. Выберите строку в таблице. Под графиком оценки появятся исходные ряды выбранного окна.
  5. Откройте вкладку «GAF и реконструкция»: верхний ряд — входные GAF-каналы, нижний — восстановленные моделью.

3. Анализ собственных захватов

Обучение модели нормы

  1. Подготовьте PCAP или PCAPNG нормального трафика. Для начальных настроек нужен захват длительностью хотя бы несколько минут.
  2. Нажмите «Добавить файлы» в разделе нормального трафика и выберите захваты.
  3. Подтвердите галочкой, что выбранные данные содержат нормальный трафик.
  4. Для начала оставьте: интервал 1 с, 32 отсчёта, шаг окна 16, исходящее направление, GASF, 20 эпох.
  5. Нажмите «Обучить модель на CPU». Ход работы отображается в журнале; операция доступна для отмены.
  6. После завершения нажмите «Сохранить модель» и сохраните файл .ngaf в «Документы».

Первые 70% времени захвата используются для обучения, последние 30% — для калибровки порога. Не включайте тестовые атаки в обучение. Демонстрационная модель рассчитана на синтетический пример; для вашей сети следует обучить свою.

Проверка другого файла

  1. При следующем запуске нажмите «Открыть модель .ngaf» и выберите сохранённую модель.
  2. Нажмите «Открыть PCAP и анализировать» и выберите новый захват.
  3. Дождитесь сообщения о завершении. Используйте таблицу, выбор окна и фильтр «Только подозрительные».

4. Понимание и сохранение результатов

MSE — ошибка восстановления GAF. Окно считается подозрительным, если его ошибка строго выше порога. Колонка «MSE / порог» показывает отношение: значение больше 1 соответствует срабатыванию.

«Вне диапазона» — количество значений признаков, вышедших за обучающий диапазон. Подробности превышений сохраняются в JSON. Значение не является счётчиком атак.

Для сохранения нажмите «Экспорт CSV / JSON». CSV удобен для таблиц; JSON включает параметры обработки, сведения об обучении и результаты по окнам. Сохраняйте отчёты и модели в свою папку «Документы».

5. Показательные тесты с разными аномалиями

  1. Нажмите «Создать демоданные» и выберите новую папку с правом записи.
  2. Обучите модель на автоматически выбранном normal.pcap.
  3. Нажмите «Проверить демосценарии» и укажите папку созданных файлов.
  4. На вкладке «Демосценарии» сравните TP/FP/FN, Precision, Recall, F1 и FPR.

Эти показатели относятся к синтетическому набору. Для результатов ВКР нужны независимые эксперименты на реальных размеченных данных.

6. Частые вопросы

«Нет полного окна». Захват слишком короткий для выбранного интервала и окна. Возьмите более длинный захват или уменьшите интервал.

«Нарушен порядок временных меток». Файл нужно предварительно упорядочить по времени, например инструментом reordercap из Wireshark.

Отчёт не сохраняется. Выберите папку «Документы». Не сохраняйте результаты поверх файлов внутри папки установленной программы.

Как удалить программу? Откройте «Параметры Windows → Приложения → NetGAF → Удалить». Ваши отчёты и модели вне папки программы сохранятся.

Где журнал ошибки запуска? Если приложение не смогло запуститься, сообщение укажет путь. По умолчанию это %LOCALAPPDATA%\NetGAF\startup.log.
