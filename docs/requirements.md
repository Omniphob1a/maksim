# Постановка задачи по НИР

Источник: приложенная пользователем рабочая редакция НИР «Анализ методов
преобразования сетевого трафика в двумерные изображения для поиска аномалий».
Документ используется как исследовательское обоснование и материал требований.
Предлагаемые в нём варианты отделены от окончательных решений пользователя.

## Реализуемый конвейер

PCAP/PCAPNG → метаданные пакетов → группировка по исходящему или входящему
IP-узлу → равномерные интервалы → пакеты/байты/уникальные порты назначения →
временные окна → фиксированная нормализация по обучению → GASF/GADF →
свёрточный автоэнкодер → MSE и порог → таблица, визуализация, CSV/JSON.

Предварительная технология: Python, PySide6, NumPy, Scapy, PyTorch CPU, Matplotlib.
Данные не отправляются внешнему сервису. Для GUI длительные задачи работают
в отдельном потоке; предусмотрена отмена между пакетами/партиями.

## Решения пользователя

- Windows и Linux, Python + PySide6.
- Офлайн-анализ PCAP/PCAPNG.
- Исходных данных пока нет; нужны демонстрационный набор и подбор реального датасета.
- Нужны показательные тесты с разными аномалиями, фиксированного перечня атак нет.

## Проверяемые критерии первого прототипа

- Читает действительные PCAP и PCAPNG, обрабатывает IP и отсутствие портов.
- Не объединяет окна через файлы, крупные разрывы и границу train/validation.
- Не подбирает масштаб по каждому окну и не использует анализируемый файл при обучении.
- GASF симметричен и восстанавливает нормализованный ряд по диагонали;
  GADF антисимметричен. Сопоставление с аналитической формулой проверяется тестами.
- Успешно проходит обучение, сохранение и загрузку весов; оценки после загрузки совпадают.
- GUI позволяет выполнить рабочую цепочку и сохранить действительные результаты.
- Синтетические проверки и реальные эксперименты имеют разные назначения.

## Что требуется уточнить

1. Обучение через интерфейс или отдельно (пока доступны оба способа).
2. Оборудование, сроки и требования руководителя.
3. Нужен ли PDF-отчёт в дополнение к CSV/JSON и установочный `.exe`.

## Исследовательская часть после уточнений

На реальных размеченных данных: независимый финальный тест, правило привязки
атак к временным окнам, сравнение с числовыми рядами/MTF, Precision/Recall/F1/FPR
и PR-AUC, время преобразования и вывода, память, влияние окна/каналов/порогов.
Исправления и ограничения CIC-IDS2017 и LYCOS-IDS2017 нужно проверить перед
формированием меток. Поточные CSV не считаются эквивалентом исходного PCAP.
